泸州美食特色主题单页网站，作者：陈运然。
在线访问：<https://newcyr.github.io/sc/>

## 本次完成的内容

### 1. 智能媒体线路（镜像优先，原站兜底）
- 图片、视频不再直接请求原站，而是先做一次线路竞速：
  `jsDelivr → jsDelivr Fastly → Statically → GitHack → GitHub Pages 原站`。
- 判定标准：首字节超过 **1.6 秒**视为「响应过长」；前 96KB 速度低于 **140KB/s** 视为「下载过慢」，
  命中任意一条立即切换下一条线路。
- 全站只测速一次并复用线路，结果写入 `localStorage` 缓存 6 小时，避免重复消耗流量。
- 任一资源在该线路上加载失败，会立刻作废线路并回退原站。
- 页面右下角（首屏）与页脚会显示当前使用的线路、首字节延迟与测速结果。

### 3. 首屏动态影像
- `assets/video/hero.mp4`：1920×1080 / 25fps / H.264 High / 22 秒 / 约 5.7MB，
  由公开来源的泸州长江—沱江交汇实景图逐帧动态重制（缓慢推拉 + 胶片颗粒 + 暗角），保留画质未强压。
- 首屏右下角提供「动态影像 开 / 关」，选择会记住；尊重系统「减少动态效果」与浏览器省流模式。
- 离开首屏自动暂停，回到首屏继续播放，省流量也省电。

### 4. 悬停动态预览
- 六张风味卡片、六个专题大图都配有 7 秒产品动态影像（1280×960，H.264）。
- 鼠标悬停 / 键盘聚焦时淡入播放，移出即暂停，不会额外占用首屏加载带宽（空闲时才预取前两条）。

## 维护

- 更换官网链接：搜索 `official-btn` 或卡片上的 `href`，同步修改 `index.html` 中对应条目即可。
- 更换首屏影像：替换 `assets/video/hero.mp4` 后提交，镜像站会自动同步。
- 调整线路阈值：编辑 `assets/js/media.js` 中的 `RULES.maxTTFB`、`RULES.minSpeed`。
